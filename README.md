## Description
This Final Project aimed to create a game of Asteroids from 1979. When starting this project, just recreating the game was the goal, i.e. having the player character, move and shoot, while dodging asteroids that come in randomly. There were indeed a lot of tuturials that helped with this project. So I thought I could put unique twist with the base game of Asteroids, add the rougelike genre into the game. When booting up, this project has the base game of Asteroids, consisting of the qualities of: Movement, Shooting, Asteroids breaking into smaller pieces, having a score and getting a Game Over. Then it has new properties from the rougelike genre, consisting of: having a upgrade screen, choosing between powerups, and having powerups stack. The game only has three powerups: Double Shot(shen shooting, shoot two times instead of one), Big Bullets(Bullets nopw have a bigger hit box, but slower fire rate), and Fire Rate up(incereases fire rate).  

This Final Project reached some goals of my proposal.md. I completed the Asteroids game but did not add new enemies and new sprites for the character and the asteroids. There was a lot of guides to do so, but I think it would not add to much uniqueness to the game. I hoped that adding a new genre to the game would help with making this project stand out. If I could add one thing to this project I would add more new Power ups, like a bomb power up, and make it so that it randomizes the power ups.
